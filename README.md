# vnavmesh unstuck CN

vnavmesh 的防卡死增强版：寻路卡住时会先自动跳跃，跳不过去就在前方放一块临时屏蔽区并重新算路绕开；界面全中文。

基于 [awgil/ffxiv_navmesh](https://github.com/awgil/ffxiv_navmesh) 修改，保留原版全部功能，额外加了脱困逻辑和汉化。

---

## 在线安装

1. 游戏里输入 `/xlplugins` 打开插件安装器
2. 点 **设置** → **插件** → **第三方插件**
3. 粘贴下面这个地址，点右边的 **+**，再点最上面的保存更改：

```
https://raw.githubusercontent.com/imztm123/ffxiv_vnavmesh-unstuck-CN/main/pluginmaster.json
```

4. 回到「所有插件」标签，搜索 `vnavmesh unstuck CN`，点安装
5. **重要**：官方仓库里也有一个 vnavmesh，两个会抢同一个 `/vnav` 命令，只能启用一个。装之前建议先禁用官方版（见下条）
6. 如果安装时提示 `Plugin at the provided path is already loaded`，说明官方版仍占着同一个版本目录：去「已安装」把官方那个**禁用**（不要卸载或删除，否则会连带清掉配置），然后**重启游戏**再装。
7. 配置兼容：除避障外的设置与原版通用，两个版本共用 `pluginConfigs\vnavmesh`，可以直接继承原版配置；但在原版里改过设置并保存后，本版新增的 6 个防卡死参数会回到默认值。（因为原版不认识这些字段，保存时会丢弃）

进游戏打 `/vnav` 打开面板，最下面就是「两阶段自动防卡死脱困」区块。

---

## 它解决了什么

原版 vnavmesh 遇到卡住只有两种反应：停下，或者按 `Stop pathing when stuck` 的设定停一会儿再重发同一条路。地形稍微刁钻一点（石头、树根、矮台阶、栅栏），角色就会一直顶着障碍原地跑。

这个版本在卡住时做了两件事：

1. **先跳**：连续 N 次自动跳跃，跳跃期间不中断前进输入，借惯性翻过矮墙台阶
2. **再绕**：跳跃用尽还卡，就在角色正前方放一块临时屏蔽区（不写进地图网格，只对本次寻路生效），强制重新算一条绕开它的路；连续 6 次无效会主动停下而不是无限折腾

## 参数怎么调

设置页最下方 6 个控件，默认值对大多数场景够用：

| 控件 | 默认 | 说明 |
|---|---|---|
| 卡住判定时间（秒） | 1.0 | 水平位移极小持续多久算卡住，调小反应快但容易误判 |
| 一阶段最大自动跳跃次数 | 2 | 设 0 就直接绕路，不跳 |
| 连续跳跃冷却间隔（秒） | 0.8 | 两次跳跃的最小间隔 |
| 二阶段局部屏蔽半径（米） | 1.5 | 屏蔽圈大小。开阔地给 2.0~2.5，副本窄门降到 1.0~1.5 |
| 屏蔽区持续时间（秒） | 15 | 过期自动清理，不会永久污染地图 |
| 启用自动防卡死 | 开 | 总开关 |

面板底部会实时显示 `当前脱困状态`（正常 / 跳跃脱困 / 局部重算绕路）和活跃屏蔽区数量。

想看得更细就 `/xllog` 打开日志，搜 `[unstuck]`。

## 和原版的关系

- `InternalName` 保持 `vnavmesh`，所以 BOCCHI、AutoDuty、visland 这些通过 IPC 调用它的插件可以正常工作
- 代价是不能和官方版同时启用（同名会抢 `/vnav` 和 IPC）
- 配置目录也是同一个 `pluginConfigs\vnavmesh`，两个版本的设置是共用的

如果只想用原版功能：把「启用自动防卡死」取消勾选即可，其余行为和原版一致。

## 常见问题

**插件列表里没有 vnavmesh**
仓库地址没加成功，或者加了没保存。删掉重加一次，确认地址是以 `pluginmaster.json` 结尾的 raw 链接。

**装完打不开 / 提示 API 不匹配**
本插件面向 Dalamud API 15（国服 15.x）。卫月大版本更新后需要作者重新编译。

**有两个 vnavmesh**
官方仓库那条没禁用。去「已安装」里关掉其中一个。

**卡住时没反应**
检查「启用自动防卡死」是否勾选；另外「卡住时停止寻路」和它是互斥的，勾了后者防卡死就不工作，面板会显示"已旁路"。

**跳了但绕不开**
把「局部屏蔽半径」调大一点（开阔地 2.0~2.5），或者把「屏蔽区持续时间」拉长到 20 秒。
